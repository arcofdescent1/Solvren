# Solvren Documentation

Documentation for product users, admins, executives, demos, deployment, and internal architecture.

Last updated: 2026-06-17

## Current Product Model

Solvren shows what revenue is at risk, what needs action, and what value was protected.

The current logged-in app is organized around:

- **Home**
- **Decisions**
- **Problems**
- **Proof**
- **Setup**

Older documents may still mention Dashboard, Reviews, Impact, Outcomes, Governance, Evidence, or Signals as primary surfaces. Those capabilities still exist, but the customer-facing product language is now Home, Decisions, Problems, Proof, and Setup.
